# Бенчмарк

Задачи, промпты и ключи лежат в `bench/tasks/`. Ключ расчёта и канарейка не копируются в промпт агента: подготовка кладёт агенту только материалы, а чату — те же байты внутри текста промпта.

Сводка и ограничения — в `docs/benchmark.md`. Пока живых парных прогонов нет, сравнение пустое. Оценщик не придумывает цифры.

Протокол и команды PowerShell печатает `python scripts/bench.py prepare --out <каталог вне репозитория>`.
