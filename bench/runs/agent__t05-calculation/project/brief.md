# Бриф

## Запрос своими словами

Посчитать по синтетической таблице `visits.csv` два целых числа: сумму колонки sat и сумму всех числовых ячеек дней недели (mon–sat) по всем неделям; записать их в `situation.md` и пройти `check`.

## Переформулировка

Когда лид продукта держит синтетический дневник посещений филиала, он хочет получить воспроизводимые суммы по субботе и по всем дневным ячейкам, чтобы опереться на проверенный расчёт, а не на ручной просмотр. Успех — оба целых числа в `situation.md` рядом с именем `visits.csv`, совпадение с `analyze` и чистый `check`. Работа клиента (гипотеза): сверить нагрузку филиала по дням без выгрузки оператора.

## Что уже принёс человек

- `bench-input/visits.csv` — синтетические посещения по дням, не выгрузка оператора (скопировано в проект как `visits.csv`).

## Вне рамок

Живые данные оператора, рынок, стратегия продукта, правки `scripts/`, `tests/`, `AGENTS.md`, `skills/` и адаптеров, запись `.env`.

## Уже видно, чего не хватает

Для этой узкой задачи расчёта внешних источников не требуется: достаточно локальной синтетической таблицы.
