# Ситуация

Синтетический разбор посещений филиала. Это не выгрузка оператора.

## Факты

В файле visits.csv сумма колонки sat равна 440 [A001.sum_sat] [E001], а сумма всех числовых ячеек дней mon, tue, wed, thu, fri, sat по всем неделям равна 1174 [A002.days_total] [E003].

## Противоречия

Нет.

## Неизвестно

Нет данных о живой нагрузке филиала и нет выгрузки оператора — только синтетическая таблица.

## Гипотезы

Синтетический ряд отражает учебный паттерн «суббота заметно выше будней»; на реальном филиале это может не держаться.
