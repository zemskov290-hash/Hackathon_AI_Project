# Журнал разработки

## 2026-11-17 — база знаний, интервью и опора чисел

Поиск по своим материалам был пересказом чата, а число в стратегии могло стоять без источника. `kb add` / `kb index` / `kb search` кладут открытый источник или свою заметку в `projects/<id>/kb/` и ищут BM25. Семантика есть только при установленном `sentence_transformers`, иначе команда остаётся на BM25 и так пишет. Выдача содержит файл или адрес, дату и фрагмент и помечена как недоверенные данные.

`interview guide` собирает вопросы по гипотезам. `interview accept` без `--consent yes` ничего не пишет. Email, телефон и имена снимаются до записи, `check` ловит остаток. `--synthetic` не оформляется согласием живого человека и везде помечен «синтетическ». Разбор цитат попадает в базу и в журнал решений. Команда из документа базы или расшифровки правилами не становится: хук её отклоняет.

В содержательном разделе стратегии число без ссылки, расчёта или интервью — ошибка `ungrounded-number`. Доля ссылок с сохранённым фрагментом ниже 90% — ошибка. Непроверенная ссылка помечается и не держит вывод одна. Скоринг `scripts/bench.py` и архив `bench/runs` не менялись. Решение: `docs/decisions/0011-kb-interview-grounding.md`. Прогон на синтетических файлах: `docs/kb-interview.md`.

## 2026-11-17 — сводка не зависит от git, capture находит agent.cmd

В закоммиченной сводке у снимков было на одно предупреждение больше, чем на чистом дереве: `check` добавляет код `tooling`, если в git грязные `scripts/` или `tests/`. Это свойство рабочей копии, не проекта. В подсчёт бенчмарка оно больше не входит. pypdf и openpyxl на `demo-family-tariffs` и `demo-analysis` список предупреждений не меняют; в CI ubuntu есть отдельный прогон с этими пакетами.

На Windows `subprocess` без оболочки не видит `agent.cmd` из-за PATHEXT, а через cmd.exe многострочный промпт режется. `capture` находит лаунчер через `which` и запускает `node.exe` и `index.js`: рядом с `agent.cmd` или из самой свежей папки `versions` по дате в имени. Путь можно задать `--agent-cmd` или `STRAT_AGENT_CMD`. Ненулевой код и пустой ответ в оценку не входят. Промпты задач и раскладка папок не менялись.

Боевые папки в `projects/` кроме `_example` не коммитятся.

## 2026-11-04 — ошибка на Windows, нашёл человек на своей машине

Клон ветки на Windows, PowerShell, git 2.45.1.windows.1, `core.autocrlf=true`. Python 3.13.1 доступен как `python`. `python3` — заглушка Microsoft Store и падает.

Что сломалось:

- `python -m unittest discover -s tests` — 14 тестов, 3 падения и 10 ошибок. В образце `test_read_material_explains_missing_pdf_package` stdout пустой, строки `pypdf` нет: сообщение по-русски не записывалось в поток с кодировкой консоли. Тесты, которые читали вывод дочернего процесса, спотыкались об ту же кодировку. В хуках был зашит `python3`.
- `python scripts/strat.py check projects/_example` — код 1, `[hash] S001..S004`: перевод строк LF стал CRLF при выгрузке, байты файла разошлись с записанным sha256.
- `init`, `status` и `resume` отработали, когда в окружении стояло `PYTHONIOENCODING=utf-8`.

Починка в ADR 0005: `.gitattributes` с `eol=lf`, хеш текста после снятия CR, stdout и stderr принудительно UTF-8, хуки на `sys.executable`, команды в README через `python`, CI матрицей `ubuntu-latest` и `windows-latest`. Локально после починки 15 тестов зелёные, включая файл с CRLF и запуск `read_material.py` при `PYTHONIOENCODING=cp1251`.

## 2026-11-04 — первая рабочая версия

Собрано за одну сессию реализации. Точные минуты сессии заранее не засекались, поэтому цифра времени здесь не ставится: в продукт не кладём неснятое измерение.

Что сделано:

- Конституция `AGENTS.md`: роль, восемь этапов, три контрольные точки человека, правило возобновления, журнал, типы свидетельств, запрет выдавать синтетику за факт, защита от команд внутри источников.
- Тонкие адаптеры Cursor, Claude Code и Copilot. Три роли (researcher, critic, respondent) описаны так, чтобы их можно было выполнить и без субагентов.
- Навыки этапов и карточки метода на русском. Навык ссылается на карточку, а не пересказывает её.
- CLI `scripts/strat.py` на стандартной библиотеке: проект, источники, свидетельства, проверка, impact, отзыв, журнал, стоимость, ворота этапов, ручной режим без API-ключа.
- Учебный проект `projects/_example` со сквозным форматом и намеренно сломанная фикстура в `tests/`.
- CI гоняет тесты и `strat check` на примере. Смоук-тест из отдельного PR не требуется.

Решения, уже согласованные до кода и зафиксированные в ADR: одно ядро правил, сначала модели подписки, граф свидетельств рядом с markdown, три роли вместо роя. Человеческая помощь на этой сессии — эти рамки в постановке. Секретов в репозитории нет.

Проверка в конце сессии: `python -m unittest discover -s tests` — 14 тестов, все зелёные. `strat check projects/_example` печатает OK. Сломанная фикстура выходит с ненулевым кодом и помечает факты без ссылки, синтетику в разделе «Факты», отозванное свидетельство, битую ссылку, нехватку вариантов, обещание без свойства и источник, которого нет.

Ошибки и ограничения, которые остались в продукте сознательно:

- `check` режет раздел «Факты» по предложениям и не понимает смысл. Пересказ без ссылки вне этого раздела пройдёт. Сокращения с точкой внутри факта лучше не писать: навык синтеза это запрещает.
- Цитата с веб-URL не сверяется с живой страницей.
- Без ключа API стоимость в журнале — запись агента, не счёт провайдера. `complete` ключ в вывод ошибки не подставляет, но и тарифов не считает.
- Хуки не включены: у Cursor и Claude Code разные файлы конфигурации, оба образца лежат в `hooks/`.
- Подтверждение человека — команда `confirm`. CLI не отличает её от самовольного вызова. Запрет агенту вызывать её без явной фразы стоит в конституции, это процесс, не криптография.
- Чтение pdf, docx и xlsx опционально. Нет пакета — понятное сообщение и ручная цитата.
- Пример не является боевой задачей. Демо-бриф хакатона на момент сборки не опубликован, поэтому кейс общий.

Дальше, не в этой версии:

- прогон на открытом публичном кейсе, не на выдуманном примере;
- дожать сопровождение: как решение живёт после нескольких волн данных, а не на одном `impact`;
- демо, когда появится брифинг задачи;
- сравнение с обычным чатом без этого репозитория на одном и том же входе;
- короткий разбор видео или PDF, если пакет чтения подключён и есть открытый файл.
