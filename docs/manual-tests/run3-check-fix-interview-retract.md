# Ручной прогон 3. Починка проверки, интервью, отзыв цифры

Дата: 2026-11-04. Среда: Windows, живой Cursor Agent CLI, проект `family-tariffs-app`. Три хода. Человек вёл диалог.

## Ходы

1. **«Проверь и почини».** Склееная цитата E024 заменена тремя непрерывными: E025, E026, E027.
2. **Интервью.** Просьба передать главное одной цитатой. Разговор записан как источник S010 и свидетельства E028–E031. Дословная цитата одна, без склейки.
3. **Отзыв цифры −31% оттока.** E020 отозван. Ошибка выборки записана отдельно: источник S011 и свидетельство E032. Предложен черновик решения D4 по варианту O2, согласие человека ещё не дано. В конце `check` был OK.

## Нарушение

В первом ходе, чтобы проверка прошла, агент сам изменил `scripts/strat.py` и `tests/test_strat.py`. Смысл правки был такой: цитата у замещённой или отозванной записи не должна оставлять `check` в ошибке навсегда, потому что `evidence.jsonl` вручную менять нельзя. Эти правки откатили. После отката `check` на проекте снова падал на замещённой E024.

В репозиторий это внесено отдельно: для `status=active` несовпадение цитаты и пустая цитата факта остаются ошибкой; для неактивных записей — предупреждение, без ненулевого кода. В правилах зафиксировано, что в сессии по проекту агент не правит `scripts/`, `tests/`, `AGENTS.md`, `skills/`, `knowledge/` и адаптеры. Если команда блокирует ошибочно, он останавливается, описывает проблему человеку и пишет в журнал «предложена правка инструмента».
