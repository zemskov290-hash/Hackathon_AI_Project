# ADR 0012. Узкий классификатор в маршруте

- Статус: принято
- Дата: 2026-11-19

## Контекст

Сильный вызов нужен, чтобы собрать картину, варианты и стратегию. Тип утверждения, список уже существующих id и выбор навыка — другие задачи: ответ обязан быть одной меткой из закрытого списка. Ошибочный «факт» без ссылки `[S…]`, `[E…]` или `[A….метрика]` нельзя оставлять только потому, что модель так написала.

У этого репозитория нет обязательного ключа API. Рабочий вход — подписка Cursor и `agent -p`. Платный OpenAI-совместимый вызов остаётся вторым контуром, как в ADR 0002, и без ключа не выполняется.

## Решение

`python scripts/strat.py classify` и MCP `strat_classify` размечают три задачи:

- `claim-type` — `fact`, `hypothesis`, `forecast`, `synthetic`;
- `impact` — существующие `E…` и `D…` проекта или `none`, дальше обычные `impact` и `propose-revision`;
- `route` — навык из `skills/`.

Ответ — JSON с `label`, `confidence` и `rationale`. Метки вне списка нет: команда завершается ошибкой и не подставляет ближайшую. Уверенность ниже порога `0.75` или противоречие правилу (факт без ссылки, синтетика без «синтетическ», прогноз без «прогноз») вызывает сильный контур. В `log.md` пишется, что выбрал дешёвый контур, почему метка исправлена и какая стоимость. Оценка по `config/model-prices.json` в поле `cost` журнала не кладётся: в тексте есть «оценка, не счёт».

Порядок бэкендов в `config/routing.json`, поле `classifier`:

1. cursor-agent, флаги `-p --trust --output-format json --workspace <пустой каталог>`. Флагов `--force` и `--mode ask` нет: ask ищет по кодовой базе, force разрешает команды, и первый живой вызов из-за этого шёл около двух минут, а дочерний процесс держал временную папку. Каталог `--workspace` пустой, лежит в `--out` или в каталоге временных файлов и не удаляется в конце вызова. Зависшее дерево гасится: на Windows `taskkill /T /F` и объект задания, которое убивает потомков при закрытии; на остальных системах сигнал группе процессов. Лёгкая модель по умолчанию `composer-2.5-fast`, сильная пустая — это модель CLI по умолчанию, без `--model` (в списке учётки она называется `auto`). `--approve-mcps` не передаётся. Ошибка одного вызова пишется в jsonl и не останавливает замер. Повтор того же `--out` пропускает уже записанные примеры.
2. Тот же протокол chat completions, что у `complete`, если уже заданы `STRAT_LLM_API_KEY` и `STRAT_MODEL_CHEAP` / `STRAT_MODEL_STRONG`.
3. Правила без сети. Они сами сеть не открывают. Если сильная модель недоступна, нарушение правила исправляют они, а невалидный JSON двух моделей остаётся ошибкой.

Специализированный оценщик (в config имя `jev`) — четвёртый, необязательный адаптер того же HTTP. `specialized.enabled` по умолчанию `false`. Ключ `STRAT_JEV_API_KEY` без этого флага вызов не включает. Отдельного пакета нет.

`check`, цитаты и скорер `scripts/bench.py` не ослаблены. Классификатор не пишет свидетельство и не закрывает этап. Навыки сбора, синтеза и пересмотра зовут его там, где раньше тип и список id выбирались сильным текстом.

Замер — `scripts/classify_bench.py`. Учебный набор из 36 вымышленных примеров лежит в `bench/classify/items.jsonl`. CI гоняет `summary --check` по правилам и по сохранённым учебным ответам `bench/classify/saved/`. Это не прогон cursor-agent. Живой прогон пишется командой `run` и кладётся в `bench/classify/runs` командой `archive`, по тому же принципу, что `bench/runs`. Пока такого каталога нет, в живой таблице прочерки.

Офлайн на этом наборе, оценка не счёт:

| Контур | Верно | Точность | Среднее время, с | Оценка стоимости, не счёт |
| --- | --- | --- | --- | --- |
| Правила | 33/36 | 0.9167 | 0.000 | 0.000000 |
| Учебный дешёвый ответ | 30/36 | 0.8333 | 0.400 | 0.001836 |
| Учебный сильный ответ | 33/36 | 0.9167 | 0.900 | 0.050760 |
| Дешёвый ответ и эскалация | 34/36 | 0.9444 | 0.550 | 0.010296 |

Источник строк — `docs/classifier-benchmark.md` и `bench/classify/summary.json`. Учебные дешёвый и сильный ответы написаны для проверки конвейера. По ним нельзя сказать, что живая модель `composer-2.5-fast` лучше или хуже модели по умолчанию.

## Последствия

Оставляем. Закрытый список и отказ ставить факт без ссылки уже работают без ключа и без счёта: правила верны в 33 из 36 учебных примеров. Эскалация на учебном корпусе поднимает итог до 34 из 36 и дешевле, чем всегда звать сильный ответ (оценка 0.010296 против 0.050760). Это польза ворот, не доказательство про живую модель.

Польза лёгкой модели подписки против модели по умолчанию не измерена: в живой таблице прочерки, пока на машине с `agent` не выполнен `run` и `archive`. Если тот прогон не обгонит правила, в config ставится `"backend": "rules"`. Команда и журнал остаются, скрытого платного вызова нет. Имя модели, которого нет в `agent --list-models`, в репозиторий как обязательное не зашито: `composer-2.5-fast` — стартовое значение, его меняют в config или через `STRAT_CLASSIFIER_CHEAP_MODEL`.
