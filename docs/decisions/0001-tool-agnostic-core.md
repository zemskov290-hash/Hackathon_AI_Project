# ADR 0001. Одно ядро правил

- Статус: принято
- Дата: 2026-11-04

## Контекст

Агентом пользуются в Cursor, Claude Code, Codex, Copilot и OpenCode. У каждой среды свой файл правил, хуки и субагенты. Если написать конституцию четыре раза, она разъедется на первой же правке.

## Решение

Единственный источник правил — `AGENTS.md`. Адаптеры тонкие: `.cursor/rules/strategist.mdc`, `CLAUDE.md`, `.github/copilot-instructions.md`. Они велят прочитать конституцию и не повторяют её. Хуки лежат в `hooks/` и по умолчанию не включены: их формат у IDE разный, а ручной вызов CLI работает везде.

## Последствия

Правило меняется в одном месте. Цена — адаптер может устареть, если IDE переименует свой входной файл. Поэтому адаптеры короткие, а обходной путь один: открыть `AGENTS.md` и вызвать `python scripts/strat.py`.
