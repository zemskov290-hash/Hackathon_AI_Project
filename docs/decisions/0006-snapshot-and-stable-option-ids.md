# ADR 0006. Снимок веб-источника и стабильный ID варианта

- Статус: принято
- Дата: 2026-11-17

## Контекст

Прогон 6 (4 ноября 2026, headless Cursor, новый проект) дошёл до desk research: `fetch` снял страницы, в реестре стало 12 активных свидетельств из 8 источников. Три дыры остались в самом прогоне. У записи E005 не было дословной цитаты, и `check` это не ловил, потому что пустая цитата считалась ошибкой только у факта. Запись E012 с низкой уверенностью вошла в рекомендацию без отдельной пометки проверки. Номера вариантов между ходами сдвинулись: агент переписал `options.md` и выдал старым развилкам новые O#.

Отдельно веб-источник, добавленный через `add-source` голым URL, не имеет файла. Цитату такого источника не с чем сверить, а `check` молчал. Подписка IDE по-прежнему пишет в журнал нулевую стоимость: это не счёт, но и не оценка.

## Решение

`fetch` обязателен для веб-страницы. Если URL уже есть в реестре, повторный `fetch` привязывает локальный снимок к той же записи и сохраняет адрес в `origin_url`. `check` помечает свидетельство, чей источник — голый URL: предупреждение, а с `--strict` ошибка. Пустая дословная цитата у любой активной записи — тоже предупреждение (у факта по-прежнему ошибка), с `--strict` ошибка. Активная запись с `confidence=low` в `strategy.md` или `decisions.md` даёт предупреждение и не считается молчаливым основанием.

ID варианта выдаёт `add-option` один раз. Следующий номер — максимум из уже выданных плюс один, включая снятые. `supersede-option` не освобождает номер: вариант остаётся в `options.md` со своим заголовком и маркером `<!-- status: superseded -->`. `check` ловит повтор ID и заголовок, который переехал на другой номер.

Оценка расхода считается отдельно от поля `cost`. Агент пишет в `log` `--input-chars` и `--output-chars`. `cost` переводит символы в токены по правилу «символы/4» и умножает на условные цены из `config/model-prices.json`. В выводе есть слово «допущение» и фраза, что это не счёт. Оценку в поле `cost` не записывают.

Подразделы продуктовой и коммуникационной стратегии проверяются по списку из навыка `06-strategy`. Пустой подраздел и заглушка — ошибка.

## Последствия

Старый проект с голым URL проходит обычный `check` с предупреждением и падает на `--strict`, пока не будет `fetch`. Гипотеза без цитаты больше не молчит. Перенумерация видна, только если ID уже лежит в `option_registry`: до первой регистрации проверка видит лишь дубли в файле. Оценка не равна счёту провайдера и не заменяет ноль подписки: ноль по-прежнему значит «счёт не пришёл».
