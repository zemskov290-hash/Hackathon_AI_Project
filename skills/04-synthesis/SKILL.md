# Синтез

Прочитай `knowledge/evidence-grading.md`. Заполни `situation.md` и убери пометку шаблона.

- В «Фактах» каждое предложение длиннее короткой реплики заканчивается ссылкой `[E..]` на запись типа `fact`. Одно предложение — одна мысль. Не начинай предложение со строчной буквы после точки: проверка режет текст по этому правилу.
- Противоречие — два активных факта, которые не могут быть верны вместе. Покажи оба id. Не усредняй.
- «Неизвестно» — вопрос плана без источника и почему его нельзя закрыть имеющимся.
- Гипотезы и прогнозы вынеси из фактов. В строке прогноза есть слово «прогноз», в строке синтетики — «синтетическ».

Запусти `python scripts/strat.py check`. Исправь все строки с ненулевым кодом. Потом `log` и `advance <проект> 4`.

Не выбирай вариант на этом этапе.
