# Сопровождение решения

Когда план проверки принят, заполни `decisions.md` и убери пометку шаблона. На каждое решение:

```text
## D1. Короткое название

- owner: роль, не выдуманное имя
- metric: что смотрим
- review_date: YYYY-MM-DD
- revisit_if: условие досрочного пересмотра
- evidence: [E001]
- option: O2
- status: open
```

Владелец — роль из брифа. Нет роли — спроси человека, не назначай сам. Метрика совпадает с планом проверки. Дата не пустая. Условие пересмотра — наблюдаемое, не «если станет плохо».

Затем `check`, `log` и `advance <проект> 8`. Дальше правки только через `revise-on-new-data`. Закрытое решение не переписывай задним числом: допиши новую запись `D2`, если выбор сменился.

Класс сопровождения остаётся на `ide`. В `log` передай объём:

```text
python scripts/strat.py log <проект> 8 "<действие>" --grounds "<почему>" --input-chars <N> --output-chars <M> --model ide/subscription
```

Затем `python scripts/strat.py cost <проект> --estimate`. Оценку в `--cost` не подставляй.
