# Варианты

Если человек просит варианты раньше этапа 5, не отвечай «метод не позволяет». Дай черновик в `options.md`: те же три роли, включая «Оставить как есть» и «Закрыть направление». В начале файла оставь маркер `<!-- preliminary -->` и фразу «гипотезы, не подтверждены, свидетельств N». У каждого варианта напиши, какие данные его подтвердят или убьют, и предложи следующий шаг сбора. `confirm` не вызывай.

На самом этапе 5 маркер `<!-- preliminary -->` убери. И в черновике, и на этапе 5 сначала `add-option`: в заголовок попадает выданный ID. До этапа 5 незарегистрированный ID — предупреждение, с этапа 5 — ошибка.

Прочитай `knowledge/premortem-steelman.md` и `knowledge/opportunity-solution-tree.md`. Варианты этого проекта не копируют `options.md` соседней папки.

Нужны минимум три варианта, которые нельзя свести к настройкам одной и той же идеи. Обязательны «Оставить как есть» и «Закрыть направление». Заголовки строго такие:

```text
### O1. Оставить как есть
<!-- role: status-quo -->

### O2. Короткое название другого пути
<!-- role: change -->

### O3. Закрыть направление
<!-- role: close -->
```

В ответе человеку не повторяй числа из файлов проекта. Если цифра нужна, в том же предложении стоит `[E014]` или `[S003]`, не `**E014**` и не `(E014)`. Иначе назови файл и id, без самой цифры. Перед отправкой прогони `python scripts/strat.py reply-check <проект> --file ответ.md` и исправь черновик. Ответ без чисел допустим.

ID выдаёт команда один раз и больше не меняется. Снятый вариант сохраняет свой номер:

```text
python scripts/strat.py add-option <проект> --title "Оставить как есть"
python scripts/strat.py supersede-option <проект> O2 --reason "почему снят"
```

В заголовок поставь тот ID, который напечатала команда. Не перенумеровывай O2 в O1, если первый вариант сняли: у нового будет следующий свободный номер, а снятый остаётся в файле со своим ID и маркером `<!-- status: superseded -->`. `check` ловит повтор ID и заголовок, который переехал на другой номер.

В каждом блоке строка `Возражение:`. Её пишет роль critic (`.claude/agents/critic.md`) или ты по той же инструкции. Возражение бьёт в сильную версию варианта. Факты в тексте варианта ссылаются на `[E..]`, прогнозы помечены словом «прогноз». Число из расчёта повторяет якорь `350 [A001.mean_price]`, а не новое «примерно».

Классы `options` и `critic` — уровень `strong`. Отдельный проход критика:

```text
python scripts/strat.py complete --tier strong --stage 5 --project <проект> --prompt-file critic.txt
```

`MODE: manual` — возражения пишешь моделью подписки. `MODE: api` — черновик всё равно проверь на опору `[E..]`. Стоимость API уже в журнале, в `--cost` оценку не подставляй.

Убери пометку шаблона. Покажи варианты человеку и остановись. После явного выбора:

```text
python scripts/strat.py confirm <проект> options --choice O2 --note "что выбрал и почему"
python scripts/strat.py advance <проект> 5
```

Не подставляй выбор сам, даже если один вариант выглядит сильнее.

Перед ответом человеку, если отвечала подписка:

```text
python scripts/strat.py log <проект> 5 "<действие>" --grounds "<почему>" --input-chars <N> --output-chars <M> --model ide/subscription
```

Затем `python scripts/strat.py cost <проект> --estimate`.
