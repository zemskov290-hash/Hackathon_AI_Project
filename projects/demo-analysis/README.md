# Синтетический расчёт и витрина

Это не боевая задача и не данные МегаФона. Таблица цен, страница «ПримерСвязь» и PNG собраны для проверки инструмента: расчёт повторяется, разбор страницы берётся из DOM, описание кадра помечено как текст модели.

Проверка: `python scripts/strat.py check projects/demo-analysis` заканчивается без ошибок. Повтор `python scripts/strat.py analyze projects/demo-analysis --id A001` печатает «Тот же результат».

Средняя цена семейных строк — 350 [A001.mean_price]. На витрине в разметке указано 399 ₽. Кадр — один пиксель, людей на нём нет.
