# Учебный пример

Это не боевая задача. Подписка «Пример», доли продления, персона «Марина» и прогноз выдуманы, чтобы показать формат файлов.

Проверка: `python scripts/strat.py check projects/_example` завершается без ошибок. Предупреждения о низкой уверенности [E003], [E004] и [E005] в стратегии ожидаемы: это учебные синтетика, прогноз и гипотеза, а не молчаливое основание.

Возобновление: `python scripts/strat.py resume projects/_example`
