# Снимок ручного прогона: семейные тарифы

Это не шаблон и не учебный вымысел вроде `projects/_example`. Папка скопирована с прогона Cursor Agent CLI на Windows 4 ноября 2026. Идентификатор в `state.json` переименован в `demo-family-tariffs`, чтобы не сталкиваться с локальным `family-tariffs-app`. Тексты, свидетельства и журнал — как их оставил агент.

Название в `state.json` — нормальный UTF-8 («Семейные тарифы в мобильном приложении»). Знаки вопроса были только в выводе консоли PowerShell.

В `decisions.md` решение D2 со статусом `proposed`, а контрольная точка `options` всё ещё `O2`: на момент прогона CLI не умел держать пересмотр в `state.json`. Отчёт: `docs/manual-tests/run1-family-tariffs.md`.
